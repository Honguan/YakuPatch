## 邏輯摘要（Godot）

- **偵測**：遊戲資料夾內有 `GDPC` 開頭的 `.pck`。資料夾內每個 pck 都處理，因為遊戲可能在執行時載入其他 pck（實測遊戲的主程式會載入另一個 pck）。
- **提取範圍**：
  - `.tscn`／`.tres`：屬性 `text`、`bbcode_text`、`hint_tooltip`、`placeholder_text`、`dialog_text`、`window_title`、`tooltip_text`，含日文才取。
  - `.gdc`（Godot 3 位元組碼 12、13 版）：字串常數含日文、不像路徑，而且沒有在任何場景當節點名、動畫名等其他字串出現，也不是識別字。後者可能被程式拿來找節點或比對，翻了會壞。
- **寫回**：整個 pck 重寫。改過的檔案附加在檔尾，目錄裡的位移、大小、MD5 改指向新資料，其他資料不動；原檔留在備份。
- **字型**：譯文有中文字時，pck 內所有 `.ttf`／`.otf` 換成 Windows 中文字型（沿用 Unity 的選法：依繁簡與粗細選雅黑、正黑等）。
- **語言預檢**：pck 內有 `*.zh*.translation` 時回報內建中文。

## 邏輯摘要（Artemis）

- **偵測**：遊戲資料夾內有 `pf6`／`pf8` 開頭的 `<名稱>.pfs`。
- **封包順序**：遊戲先載入 `<名稱>.pfs`，再依編號載入 `.pfs.000`、`.001`……，後面的同名檔案覆蓋前面的。每個檔案只取最後生效的那份來翻。
- **提取範圍**：
  - `.ast`：Lua 表格，一行一個項目。只讀 `text = { ja = {...} }`：`name = {"話者"}` 取成 `name`，同一則訊息的每行字串取成 `dialogue` 並分在同一組；`select = { ja = {...} }` 的字串取成 `choice`。en／cn／tw 等其他語言不讀。
  - `.tbl`：`key = "文字",` 這種行，含假名才取（系統按鈕說明等），取成 `ui`。
  - 字串支援 `"..."`（含跳脫字元）與 `[[...]]`；寫回一律用 `"..."` 並跳脫。
- **寫回**：不改原封包。改過的檔案打包成新的 `<名稱>.pfs.NNN`，編號接在現有最大編號之後，格式（pf6／pf8）跟主封包相同。重建現有的中文補丁 `.pfs.001` 與另一款遊戲的 `.pfs.001` 都與原檔逐位元相同。
- **字型**：不換。實測遊戲用思源黑體，各地區版本都含簡繁字形；現成的中文補丁也只改劇本與表格。
- **語言預檢**：劇本裡有 `cn`／`tw`／`zh*` 區塊時回報內建中文。

## 新增 shortcut 與已知限制

- **字型全換**：pck 內所有字型都換成中文字型，包括只有英文的字型。沒有檢查字型原本缺哪些字。
- **`.gdc` 用猜的**：字串常數只要含日文、不像路徑、不和其他名稱重複就翻；被程式拿來比對的字串可能因此失效。和名稱重複的會保留原文，所以程式動態設定的部分按鈕提示可能仍是日文。
- **不支援**：加密 pck、嵌在 `.exe` 內的 pck、Godot 4 的二進位場景（`.scn`）與位元組碼、Dialogic 時間軸（`.dtl`）、動畫軌道裡的文字、Godot 4 匯入的字型（`.fontdata`）。
- **記憶體**：pck 整檔讀進記憶體，大小上限 512 MB。
- **Artemis 讀音**：`{"txruby", text="讀音"}` 保留原樣，翻譯後讀音會標在中文字上方。
- **Artemis 範圍**：`.lua` 系統腳本（多是註解與除錯訊息）不翻；按鈕圖片上的文字不翻；跨行的 `[[...]]` 長字串不取。只支援 UTF-8 劇本。
- **Artemis 實測樣本**：庫內沒有純日文的 Artemis 遊戲，實測用的是移除中文補丁後的日文原版。
